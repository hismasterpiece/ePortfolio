# ePortfolio

A simple ePortfolio to store document links and group them into categories like:
- Year 1 / Semester 1
- Year 1 / Semester 2
- Year 2 / Semester 1

## How to use
1. Open `/home/runner/work/ePortfolio/ePortfolio/index.html` in your browser.
2. Add:
   - document title
   - document URL
   - category path (for example: `Year 1 / Semester 1`)
3. Your links are shown in a nested category tree and saved in browser local storage.
